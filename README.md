# 👟 NdulaBox - Multi-Vendor Shoe Showcase Platform

![NdulaBox Logo](src/assets/logo.png)

> A modern, full-featured multi-vendor shoe showcase platform with 360° product views, Cloudinary image hosting, Firebase authentication, and a powerful admin panel.

## ✨ Features

### 🛍️ Customer Experience
- **360° Product Viewer** - Auto-rotating and drag-enabled product images
- **Dynamic Category Filtering** - Browse by Gents, Ladies, Kids, Running, Casual, Skate
- **Smooth Image Transitions** - Professional fade effects between product views
- **Responsive Design** - Perfect on desktop, tablet, and mobile
- **Instant Contact** - Floating WhatsApp and Call buttons for instant customer engagement
- **Coming Soon** - Virtual Try-On feature (placeholder active)

### 👨‍💼 Admin Panel
- **Google Authentication** - Secure login with Google account
- **Multi-Vendor Support** - Each vendor manages their own shoe collection
- **Easy Product Management** - Add, update, and delete shoes
- **Bulk Image Upload** - Upload 8-12 images per shoe for 360° rotation
- **Cloudinary Integration** - Automatic image storage and optimization
- **Real-time Database** - Firebase Firestore for instant data sync
- **User-Specific Data** - Each vendor sees only their own products

### ☁️ Technical Features
- **Cloudinary CDN** - Fast image delivery with automatic optimization
- **Firebase Authentication** - Secure Google sign-in
- **Firebase Firestore** - Real-time database with user-specific data
- **React Router** - Clean, navigable URLs
- **Modular CSS** - Well-organized, maintainable styles
- **360° Rotation** - Interactive product views
